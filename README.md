# 📁 Meus Prompts

Repositório com prompts que crio e refino no meu dia a dia, parte prática, parte estudo de engenharia de prompt. Cada prompt é documentado com contexto, objetivo e o raciocínio por trás das escolhas feitas.

## 🗂️ Estrutura do repositório

```
meus-prompts/
├── README.md
├── google-embaixador-estudantil/
│   └── ...
├── prompts-estudos/
│   └── ...
└── prompts-codigo/
    └── ...
```

### `google-embaixador-estudantil/`
Prompts e desafios desenvolvidos como parte do **Programa Embaixador Estudantil do Google**. Cada arquivo documenta o desafio proposto, o prompt original (quando aplicável), o prompt reescrito/otimizado e a justificativa das melhorias.

### `prompts-estudos/`
Prompts voltados para apoiar minha rotina acadêmica: planos de estudo, resumos, revisão de conteúdo, geração de exercícios e organização de matérias do curso de Ciência dos Dados.

### `prompts-codigo/`
Prompts usados para depuração, revisão e explicação de código —úteis em disciplinas como Redes Neurais, Processamento Paralelo e nos Projetos Integradores.

## 📄 Formato dos arquivos

Cada prompt é documentado em Markdown (`.md`) seguindo esta estrutura:

```markdown
## Prompt: [nome do prompt]

**Objetivo:** o que esse prompt resolve.

**Prompt:**
```
[texto do prompt aqui, com placeholders entre colchetes]
```

**Por que funciona:** raciocínio por trás das escolhas feitas (o que cada parte do prompt resolve).
```

## 🎯 Motivação

Este repositório serve como portfólio pessoal de prompt engineering, reunindo aprendizados práticos obtidos ao longo do curso de Ciência dos Dados (UFMS) e do Programa Embaixador Estudantil do Google.
